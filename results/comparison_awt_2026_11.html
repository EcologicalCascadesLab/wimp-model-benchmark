3. How the by-image frame was picked

The plan was each sequence's frame with the highest MegaDetector score. WIMP's exports did not make that possible for nearly all sequences: the PROD source project could not be exported with boxes (account is Project coordinator, not Maintainer), and the TEST bounding-box export holds human-drawn boxes, not MegaDetector's. Those sequences use the middle frame; blank sequences use the middle frame by design.

Picked by detector score Middle frame (no detector score available) Middle frame (blank, by design)

How to read detector recall across the sets. Random frames (by sequence) include frames where the animal has left the view, so recall there is a lower bound. Frames chosen by the detector's own score would be an upper bound. Middle frames are chosen without the detector, so this set sits between the two and is the fairest single-image estimate available. Species-classifier comparisons are fair in both sets, since neither was chosen using the classifier.
